# Solnari 0.5.0 — Apple Silicon Preview

macOS 14 이상을 실행하는 Apple Silicon Mac용 릴리즈입니다. 앱 버전은 **0.5.0**, 빌드 번호는 **7**입니다.

## Kubernetes 경유 개인 IAM 인증

Cloud SQL Auth Proxy 하나를 공유하면서 각자의 로컬 Google IAM 계정으로 PostgreSQL에 로그인할 수 있습니다.

1. 연결 방식 **Kubernetes**, 모드 **기존 리소스**를 선택합니다.
2. Proxy의 context, namespace, Service 또는 Pod와 포트를 입력합니다.
3. **개인 Cloud SQL IAM 인증 사용**을 켜고 IAM DB 사용자명과 DB명을 입력합니다.
4. 연결하면 로컬 Application Default Credentials로 임시 로그인 토큰을 발급합니다.

Proxy는 `--private-ip`를 사용하고 `--auto-iam-authn`은 끈 상태여야 합니다. Proxy의 IAM은 Cloud SQL 연결을 허가하고, 개인 IAM은 DB 로그인과 DB 권한을 구분합니다. 개인 계정에는 IAM DB 로그인 권한, 인스턴스 IAM 사용자·그룹 등록과 필요한 PostgreSQL 권한이 있어야 합니다.

토큰은 비밀번호 저장소나 내보낸 연결 파일에 저장하지 않습니다. 기존 비밀번호 연결도 계속 사용할 수 있습니다.

**제한:** 연결·연결 테스트·명시적 재연결 시 토큰을 발급합니다. 백그라운드 연결 풀의 토큰 자동 교체는 지원하지 않으므로, 토큰 만료 후 새 물리 연결이 필요하면 다시 연결하세요. 실제 Cloud SQL Proxy를 통한 접속 검증은 사용 환경에서 수행해야 합니다.

## 설치

`Solnari-0.5.0-macos-arm64-unsigned.dmg`를 열고 앱을 **응용 프로그램** 폴더로 복사합니다. SHA-256 파일을 함께 제공합니다.

기존 Preview와 동일하게 ad-hoc 서명되어 있으며 Apple notarization을 받지 않았습니다. 최초 실행이 차단되면 [설치 안내](https://github.com/dreamyoungs/solnari/blob/v0.5.0/docs/install-unsigned-macos.ko.md)를 따르세요.

---

This Apple silicon preview adds personal ADC-based IAM database authentication through existing
Kubernetes Cloud SQL Auth Proxy resources for PostgreSQL. Tokens are obtained for connection tests
and explicit connections/reconnections, and are never saved in connection profiles or the password
vault. The Proxy must run without automatic IAM authentication. Background pool credential rotation
is not supported; reconnect if a new physical connection is needed after token expiry. Live Proxy
validation remains environment-specific. The DMG is ad-hoc signed and not notarized.
