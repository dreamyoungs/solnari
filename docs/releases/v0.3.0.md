# Solnari 0.3.0 — Apple Silicon Preview

macOS 14 이상을 실행하는 Apple Silicon Mac용 릴리즈입니다. 앱 버전은 **0.3.0**, 빌드 번호는 **5**입니다.

## 주요 변경사항

- 실행 계획 조회·취소와 생성된 SQL 복사를 지원합니다.
- 스키마 상세 정보를 미리보기 탭으로 열고 필요한 탭을 고정할 수 있습니다.
- PostgreSQL·MySQL·SQLite에 맞춰 SQL을 정렬하고 선택 영역과 실행 취소를 지원합니다.
- Codex SQL 어시스턴트를 연결했습니다. 전송할 문맥을 선택하고, 제안된 SQL을 검토한 뒤 새 쿼리 탭에 넣을 수 있습니다. SQL은 자동 실행하지 않습니다.
- 연결 프로필 복제·가져오기·내보내기, 데이터베이스 배지, 설정 단축키와 설치용 DMG 화면을 추가했습니다.
- 결과 셀에서 값에 맞는 SELECT·DELETE 초안을 생성할 수 있습니다.

## 오류 수정

- 새 연결 창에서 아이콘이 커져 데이터베이스 선택을 가리던 문제를 수정했습니다.
- 탐색기에서 PostgreSQL의 `pg_temp_*` 임시 스키마를 숨겼습니다.
- Codex 로그인 시 키체인을 찾지 못하거나 인증을 저장하지 못하던 접근 제한을 수정했습니다.
- Node 백엔드가 연결된 상태에서 Codex 초기화가 멈추던 문제를 수정했습니다.
- Cloud SQL JSON 표시와 쿼리 실패 후 이전 결과가 남는 문제를 수정했습니다.

## 설치

1. `Solnari-0.3.0-macos-arm64-unsigned.dmg`를 내려받습니다. 함께 제공되는 SHA-256 파일로 무결성을 확인할 수 있습니다.
2. DMG를 열고 `Solnari.app`을 **응용 프로그램** 폴더로 복사합니다.
3. 최초 실행 시 macOS가 차단하면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 승인합니다.

이 Preview는 기존 릴리즈와 동일하게 ad-hoc 서명되어 있으며 Apple notarization을 받지 않았습니다. 자세한 절차는 [설치 안내](https://github.com/dreamyoungs/solnari/blob/v0.3.0/docs/install-unsigned-macos.ko.md)를 참고해 주세요.

## Codex 사용

지원하는 Codex CLI 0.153.x가 Mac에 설치되어 있어야 합니다. Solnari의 **로그인** 메뉴에서 브라우저 또는 기기 코드 방식으로 ChatGPT에 로그인합니다. Solnari의 인증은 기존 Codex 설정·인증과 분리되며 macOS 키체인에 저장됩니다.

대화와 스키마 탭은 메모리에 유지되며 앱을 종료하면 복원되지 않습니다. 선택한 문맥은 AI 답변 생성을 위해 OpenAI에 전송됩니다.

전체 변경사항은 [CHANGELOG.md](https://github.com/dreamyoungs/solnari/blob/v0.3.0/CHANGELOG.md)에서 확인할 수 있습니다.

---

This Apple silicon preview adds safe execution plans, schema tabs, dialect-aware SQL formatting,
and an opt-in Codex SQL assistant. It fixes database-engine selection, hides PostgreSQL temporary
schemas, and restores keychain access for Codex sign-in. The DMG is ad-hoc signed and not notarized.
The assistant requires an installed Codex CLI 0.153.x and a separate ChatGPT sign-in for Solnari.
