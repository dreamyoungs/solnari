# Solnari 0.2.1 — Apple Silicon Preview

macOS 14 이상을 실행하는 Apple Silicon Mac용 버그 수정 릴리즈입니다.

## 설치

1. `Solnari-0.2.1-macos-arm64-unsigned.dmg`를 내려받습니다. 필요하면 함께 제공하는 SHA-256
   파일로 무결성을 확인할 수 있습니다.
2. DMG를 열고 `Solnari.app`을 **응용 프로그램** 폴더로 복사합니다.
3. Solnari를 한 번 실행하고 macOS 경고창에서 **완료**를 누릅니다.
4. **시스템 설정 → 개인정보 보호 및 보안**을 열고 화면 맨 아래까지 내려간 다음 Solnari
   메시지 옆의 **그래도 열기**를 누릅니다.
5. 암호 또는 Touch ID로 승인하고 다시 **그래도 열기**를 선택합니다.

## macOS 경고가 표시되는 이유

이 무료 오픈소스 preview는 ad-hoc 서명되어 있으며 notarization되지 않았습니다. 이 경고는
macOS가 악성 코드를 발견했다는 뜻이 아니라 Apple이 이 build를 확인할 수 없다는 뜻입니다.
반드시 이 GitHub 저장소에서 받은 파일에만 위 절차를 사용해 주세요.

## 수정 사항

- 모든 Solnari 창을 닫은 뒤 Dock 아이콘을 클릭하면 메인 창이 다시 열립니다.

전체 변경사항은 [CHANGELOG.md](../../CHANGELOG.md)를 확인해 주세요.

---

This Apple silicon preview fixes reopening Solnari from the Dock after all app windows have been
closed. The DMG is ad-hoc signed and not notarized. Copy the app to Applications, attempt to launch
it once, then use **Open Anyway** at the bottom of **System Settings → Privacy & Security**.
