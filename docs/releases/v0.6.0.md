# Solnari 0.6.0 — Apple Silicon Preview

macOS 14 이상, Apple Silicon용 버전 **0.6.0**, 빌드 **10**입니다.

- PostgreSQL 연결 상단의 DB 이름에서 같은 서버의 다른 데이터베이스를 선택할 수 있습니다.
  목록 새로고침과 이름 직접 입력을 지원하며 저장된 연결을 복제할 필요가 없습니다.
- DB별 쿼리 탭과 결과를 메모리에 보관합니다. 대상 DB의 접속과 스키마 조회가 성공한 뒤
  전환하고, 접속 실패나 시간 초과 시 기존 DB와 작업을 유지합니다.
- 저장된 기본 DB, 로그인, 네트워크 경로와 읽기 전용 설정을 유지합니다. 전환하면 Codex
  문맥을 초기화하고 MCP 실행 대상 ID를 갱신해 이전 DB를 대상으로 한 쓰기 요청을 거부합니다.
- 긴 SQL을 붙여넣었을 때 편집기가 연결 정보·쿼리 탭·실행 버튼을 덮던 문제를 수정했습니다.
  줄 번호가 본문과 함께 스크롤되고 실제 텍스트 줄 높이에 맞춰 표시됩니다.
- 간접 의존성 brace-expansion을 2.1.7로 갱신해 보고된 서비스 거부 취약점을 해결했습니다.

로컬 PostgreSQL의 읽기/쓰기·읽기 전용 전환, 접속 실패 복구, DB별 작업 복원, 재연결,
세션 정리와 오래된 MCP ID 거부를 검증했습니다. LF·CRLF 긴 SQL 붙여넣기와 스크롤 회귀
테스트, 한국어·영어 및 밝은·어두운 테마 화면을 확인했습니다. Cloud SQL·SSH·Kubernetes의
실제 환경에서 DB를 전환하는 동작은 미검증입니다. DB 전환은 새 세션을 사용하므로 기존
세션 설정과 임시 테이블은 이어지지 않습니다.

`Solnari-0.6.0-macos-arm64-unsigned.dmg`와 SHA-256 파일을 제공합니다. 기존 Preview와
동일한 ad-hoc 서명이며 Apple notarization은 받지 않았습니다.

This preview adds PostgreSQL database switching within a saved connection, preserves separate
workspaces and read-only settings, rejects stale MCP write targets, and fixes editor layout after
long SQL pastes. The Apple Silicon DMG is ad-hoc signed and not notarized.
