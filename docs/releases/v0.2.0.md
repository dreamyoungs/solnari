# Solnari 0.2.0 — Apple Silicon Preview

macOS 14 이상을 실행하는 Apple Silicon Mac용 첫 번째 버전 릴리즈입니다.

## 설치

1. `Solnari-0.2.0-macos-arm64-unsigned.dmg`를 내려받습니다. 필요하면 함께 제공하는 SHA-256
   파일로 무결성을 확인할 수 있습니다.
2. DMG를 열고 `Solnari.app`을 **응용 프로그램** 폴더로 복사합니다.
3. Solnari를 한 번 실행하고 macOS 경고창에서 **완료**를 누릅니다.
4. **시스템 설정 → 개인정보 보호 및 보안**을 열고 화면 맨 아래까지 내려간 다음 Solnari
   메시지 옆의 **그래도 열기**를 누릅니다.
5. 암호 또는 Touch ID로 승인하고 다시 **그래도 열기**를 선택합니다.

## macOS 경고가 표시되는 이유

이 무료 오픈소스 preview는 ad-hoc 서명되어 있으며, 프로젝트가 아직 유료 Apple Developer
Program에 가입하지 않아 notarization되지 않았습니다. 이 경고는 macOS가 악성 코드를
발견했다는 뜻이 아니라 Apple이 이 build를 확인할 수 없다는 뜻입니다. 반드시 이 GitHub
저장소에서 받은 파일에만 위 절차를 사용해 주세요.

보안 예외를 승인하고 싶지 않다면 README의 안내에 따라 소스에서 직접 빌드할 수 있습니다.
프로젝트 사용과 GitHub Stars가 충분히 늘어나면 Apple Developer Program에 등록하고 Developer
ID로 서명·notarization한 릴리즈를 제공할 계획입니다.

## 주요 변경사항

- 저장된 연결마다 SQL 탭, 결과와 스키마 상태를 독립적으로 유지
- 테이블이 없는 PostgreSQL `public` 등의 빈 스키마도 탐색기에 표시
- 연결 입력에 붙여넣은 값을 한 줄로 정규화하고 Cloud SQL IAM 안내를 명확하게 개선
- Apple Silicon DMG 패키징과 향후 Developer ID notarization workflow 준비

전체 변경사항은 [CHANGELOG.md](../../CHANGELOG.md)를 확인해 주세요.

---

This is the first versioned Solnari preview for Apple silicon Macs running macOS 14 or newer. The
DMG is ad-hoc signed and not notarized. Copy the app to Applications, attempt to launch it once,
then use **Open Anyway** at the bottom of **System Settings → Privacy & Security**. If you prefer
not to approve the exception, follow the README to build from source. A Developer ID-signed and
notarized release is planned when project use and GitHub Stars grow enough.
