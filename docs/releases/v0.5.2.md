# Solnari 0.5.2 — Apple Silicon Preview

macOS 14 이상, Apple Silicon용 버전 **0.5.2**, 빌드 **9**입니다.

- 성공한 PostgreSQL 다중 SQL 트랜잭션을 실패로 표시하던 문제를 수정했습니다.
- 명령 결과, 커밋·롤백 상태, 실패 위치 및 서버 오류를 구분해 표시합니다.
- GRANT/REVOKE 전후의 조회 가능한 역할 membership·테이블 권한을 비교할 수 있습니다.
- MCP 쓰기 지원을 유지하면서 권한 거부와 다음 실행 단계를 구조적으로 안내합니다.
- Node 통신 멈춤·재시작 경합을 수정하고 Codex CLI 0.155.0-alpha.16을 지원합니다.

직접 연결의 트랜잭션은 완결된 BEGIN … COMMIT/ROLLBACK 스크립트로 실행해야 합니다.
권한 검증은 시스템 스키마를 제외한 테이블 권한과 membership 비교이며 전체 권한이나
변경 의도의 검증을 뜻하지 않습니다. 로컬 PostgreSQL·SQLite와 실제 Codex 초기화는
검증했지만 Cloud SQL·MySQL 실서버 및 로그인된 Codex 모델 응답은 미검증입니다.

`Solnari-0.5.2-macos-arm64-unsigned.dmg`와 SHA-256 파일을 제공합니다. 기존 Preview와
동일한 ad-hoc 서명이며 Apple notarization은 받지 않았습니다.

This preview fixes PostgreSQL transaction reporting and Node transport races, improves command
results and MCP permission guidance, and adds verified Codex CLI 0.155.0-alpha.16 compatibility.
The Apple Silicon DMG is ad-hoc signed and not notarized.
