# Solnari 0.4.0 — Apple Silicon Preview

macOS 14 이상을 실행하는 Apple Silicon Mac용 릴리즈입니다. 앱 버전은 **0.4.0**, 빌드 번호는 **6**입니다.

## MCP 쓰기 지원

- **읽기 전용 연결**에서는 기존처럼 조회만 허용합니다.
- **쓰기 허용 연결**에서는 새 `solnari_execute_query` 도구로 SELECT·INSERT·UPDATE·DELETE·DDL을 실행할 수 있습니다.
- 실행 직전에 선택한 연결 ID와 실제 DB 세션의 권한을 확인합니다. 연결이 바뀌었거나 읽기 전용이면 요청을 거부합니다.
- 변경 쿼리 후 탐색기 스키마를 갱신합니다.
- 완료된 변경의 결과가 너무 크면 오류 대신 결과를 생략한 성공 응답을 반환합니다.

MCP 접근을 켜고 연결에서 쓰기를 허용하면 변경 쿼리가 DB 계정의 권한 범위에서 즉시 실행됩니다. 별도의 Solnari 승인창은 없으며 외부 MCP 클라이언트의 승인 정책은 그대로 적용됩니다. `maxRows`는 반환 행 수만 제한하며 변경되는 행 수를 제한하지 않습니다. 시간 초과·통신 오류 후에는 실행 여부를 확인하고 재시도해야 합니다.

## 업데이트 후 사용

1. 앱을 교체하고 실행합니다.
2. Codex의 Solnari MCP 연결 또는 Codex 앱을 재시작해 새 도구 목록을 불러옵니다.
3. Solnari에서 대상 연결을 **쓰기 허용**으로 저장·재연결합니다.
4. MCP 클라이언트는 `solnari_get_active_connection`에서 받은 `connectionID`로 쿼리를 실행합니다.

자세한 사용법은 [MCP 접근 안내](https://github.com/dreamyoungs/solnari/blob/v0.4.0/docs/mcp-access.ko.md)를 참고해 주세요.

## 설치

`Solnari-0.4.0-macos-arm64-unsigned.dmg`를 열고 `Solnari.app`을 **응용 프로그램** 폴더로 복사합니다. SHA-256 파일을 함께 제공합니다.

이 Preview는 기존 릴리즈와 동일하게 ad-hoc 서명되어 있으며 Apple notarization을 받지 않았습니다. 최초 실행 시 차단되면 [설치 안내](https://github.com/dreamyoungs/solnari/blob/v0.4.0/docs/install-unsigned-macos.ko.md)의 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기** 절차를 따릅니다.

---

This Apple silicon preview adds MCP SQL execution for Read / Write connections. Solnari checks the
selected connection ID and live-session permissions before execution; read-only connections remain
protected. Writes execute immediately under the database role's permissions. Restart the Solnari
MCP connection after updating to discover the new tool. The DMG is ad-hoc signed and not notarized.
