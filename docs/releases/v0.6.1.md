# Solnari 0.6.1 — Apple Silicon Preview

macOS 14 이상, Apple Silicon용 버전 **0.6.1**, 빌드 **11**입니다.

- 연결 편집 화면에서 기존 SSH 개인 키 파일을 선택할 수 있습니다. 키 내용이나 암호를
  복제하지 않고 이 Mac의 파일 경로만 저장하며, 경로는 연결 프로필 내보내기에 포함하지 않습니다.
- 기존 OpenSSH 서버 신원 검증을 유지하며 접속 제한 시간과 keepalive를 적용합니다.
  DB는 SSH 서버에서 접근하는 주소를 사용하고 Mac에서는 loopback 임시 포트만 엽니다.
- 터널 단절이 감지되면 연결을 실패로 표시하고 결과·메시지 영역에도 번역된 오류를 표시합니다.
- 단절 후에는 명시적으로 재연결해야 합니다. 재연결은 새 터널과 DB 세션을 만들며
  이전 쿼리나 트랜잭션을 자동 재실행하지 않습니다.

MCP client/server SDK를 같은 2.x 계열의 2.4.0에 고정하고 호환 의존성을 갱신했습니다.
릴리스 잠금 파일의 npm audit 보고는 취약점 0건입니다.

실제 Linux PostgreSQL 로그인, 읽기 조회, 앱이 만든 터널의 종료와 수동 재연결을 확인했습니다.
재연결 뒤 새 DB 세션에서 조회가 성공했으며 기존 수동 터널과 DB 데이터·서버 보안 설정은
변경하지 않았습니다. 전체 Swift 테스트는 선택적 외부 환경 테스트를 제외하고 성공했습니다.
절전 복귀, 장시간 네트워크 장애, 진행 중 트랜잭션 단절은 미검증입니다.

`Solnari-0.6.1-macos-arm64-unsigned.dmg`와 SHA-256 파일을 제공합니다. 기존 Preview와
동일한 ad-hoc 서명이며 Apple Developer ID 서명 및 notarization은 받지 않았습니다.
최초 실행 안내: [한국어](https://github.com/dreamyoungs/solnari/blob/v0.6.1/docs/install-unsigned-macos.ko.md),
[English](https://github.com/dreamyoungs/solnari/blob/v0.6.1/docs/install-unsigned-macos.en.md).

This preview adds an SSH private-key file picker, preserves host-key verification, and improves
SSH failure status and localized diagnostics. Manual reconnect creates a fresh database session;
queries and transactions are never replayed automatically. The Apple Silicon DMG is ad-hoc signed
and not notarized. Sleep/wake recovery and disconnects during an active transaction remain untested.
