# Solnari 0.7.0 — Apple Silicon Preview

macOS 14 이상, Apple Silicon용 버전 **0.7.0**, 빌드 **12**입니다.

- MCP에서 현재 연결된 개발·운영 DB 목록을 조회하고, 각 요청에 사용할 DB를 지정할 수 있습니다.
  앱 화면에서 선택한 연결이나 다른 MCP 클라이언트의 선택에 영향을 받지 않습니다.
- `설정 → MCP 접근 → Codex에 연결` 버튼으로 등록할 수 있습니다. 설치된 Codex 앱의 실행 파일을
  사용하므로 별도 CLI·Node·MCP 설치가 필요 없습니다. 등록 뒤 Codex를 재시작하세요.
- 연결 설정에 **MCP 동시 실행 수**를 추가했습니다. 기본 3개, 연결별 1~10개이며 저장·재연결 시
  적용됩니다. 기존 프로필은 별도 변경 없이 기본값 3개로 동작합니다.
- MCP 요청은 앱과 독립된 DB 세션을 필요할 때 열고 완료 후 닫습니다. 한도가 찼으면 대기열 없이
  `MCP_SESSION_LIMIT_REACHED`로 거절하며, 다른 DB 연결의 한도는 독립적입니다.
- 임시 객체·세션 설정·트랜잭션은 다음 MCP 요청으로 이어지지 않습니다. 트랜잭션은 해당 엔진이
  지원하는 한 번의 SQL 요청 안에서 완료해야 하며 미완료 작업은 세션 종료 시 롤백됩니다.
- 기존 접근 권한, credential 비노출, 로컬 전용 MCP 및 잠금·절전 시 연결 해제 정책을 유지합니다.
  SSH 터널 단절 시 실패 표시와 명시적 재연결 요구도 유지합니다.

SQLite와 격리된 로컬 PostgreSQL에서 MCP 전용 세션 3개와 앱 세션의 독립 실행, 연결별 한도,
슬롯 반환, 권한 검사와 DB 전환을 확인했습니다. Codex 등록은 개인 설정 대신 임시 설정으로
검증했습니다. 실제 MySQL·Cloud SQL·SSH·Kubernetes의 MCP 동시 실행은 미검증입니다.
각 요청에 새 연결·인증 비용이 들며 SQLite 쓰기 잠금 등 DB 자체의 제한은 그대로 적용됩니다.

`Solnari-0.7.0-macos-arm64-unsigned.dmg`와 SHA-256 파일을 제공합니다. 기존 Preview와
동일한 ad-hoc 서명이며 Apple Developer ID 서명 및 notarization은 받지 않았습니다.
최초 실행 안내: [한국어](https://github.com/dreamyoungs/solnari/blob/v0.7.0/docs/install-unsigned-macos.ko.md),
[English](https://github.com/dreamyoungs/solnari/blob/v0.7.0/docs/install-unsigned-macos.en.md).

This preview lets MCP clients choose an already connected database per request and register Solnari
from its Settings window. Per-connection MCP concurrency defaults to 3 and is configurable from
1 to 10. Each request opens and closes a dedicated session; app sessions remain independent.
Excess requests are rejected without queuing. Transactions and temporary session state do not persist
across requests. The Apple Silicon DMG is ad-hoc signed and not notarized.
