# Solnari 0.5.1 — Apple Silicon Preview

macOS 14 이상을 실행하는 Apple Silicon Mac용 릴리즈입니다. 앱 버전은 **0.5.1**, 빌드 번호는 **8**입니다.

## 더 명확한 DB 로그인 선택

IAM 켜기·끄기 체크박스를 **DB 로그인 방식** 메뉴로 바꿨습니다.

- **Google 계정으로 로그인 (IAM)**: 이 Mac의 Google 인증 정보로 로그인합니다. DB 비밀번호는 필요 없습니다.
- **DB ID·비밀번호로 로그인**: `postgres` 같은 DB 계정과 해당 계정의 비밀번호를 입력합니다.

Cloud SQL과 Kubernetes 기존 리소스의 PostgreSQL 연결에 적용됩니다. 선택에 따라 입력칸과 설명이 바뀝니다. Cloud SQL 연결 권한은 DB 로그인과 제목을 구분하고, Kubernetes·Proxy 설정 설명은 펼쳐 보는 안내로 옮겼습니다. 기존 프로필과 인증 동작은 유지됩니다.

Kubernetes에서 Google 계정 로그인을 사용하려면 Proxy의 `--auto-iam-authn` 옵션을 꺼야 합니다. 개인 IAM 토큰은 연결·연결 테스트·명시적 재연결 시 발급하며 저장하지 않습니다. 백그라운드 연결 풀의 토큰 자동 교체는 지원하지 않으므로, 만료 후 새 물리 연결이 필요하면 다시 연결하세요. 실제 Proxy 접속은 사용 환경에서 검증해 주세요.

## 설치

`Solnari-0.5.1-macos-arm64-unsigned.dmg`를 열고 앱을 **응용 프로그램** 폴더로 복사합니다. SHA-256 파일을 함께 제공합니다.

기존 Preview와 동일하게 ad-hoc 서명되어 있으며 Apple notarization을 받지 않았습니다. 최초 실행이 차단되면 [설치 안내](https://github.com/dreamyoungs/solnari/blob/v0.5.1/docs/install-unsigned-macos.ko.md)를 따르세요.

---

This Apple silicon preview replaces IAM toggles with explicit Google account or database
ID/password login choices. Connection authorization and database login are labeled separately,
and Kubernetes Proxy setup details are expandable. Existing profiles and authentication behavior
remain unchanged. The DMG is ad-hoc signed and not notarized.
