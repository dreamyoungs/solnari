# 스키마 상세 탭

탐색기의 객체를 한 번 클릭하면 기울임 제목과 고정 버튼이 있는 미리보기 탭을 엽니다. 다른 객체를 선택하면 같은 미리보기 탭을 재사용합니다. 더블 클릭, 탐색기 컨텍스트 메뉴의 **구조 보기**, 또는 탭의 **탭 고정** 버튼은 일반 탭으로 고정합니다. 고정 버튼은 키보드와 VoiceOver로도 사용할 수 있습니다.

이미 열려 있는 객체는 기존 탭을 선택하며 중복 생성하지 않습니다. 여러 고정 탭은 독립적으로 닫을 수 있습니다. 마지막 탭을 닫으면 빈 쿼리 탭을 만듭니다. SELECT 생성 및 데이터 열기는 별도 쿼리 탭을 생성하여 상세 탭을 보존합니다. 현재 상세 화면은 편집을 지원하지 않으므로 편집 시 자동 고정은 적용되지 않습니다.

연결을 전환하면 각 연결의 탭을 메모리에서 복원합니다. 앱 재시작 후에는 상세 탭이나 메타데이터를 디스크에서 복원하지 않습니다. 연결 해제 시 상세 내용을 지우고 연결 오류를 표시합니다. 스키마 새로고침으로 삭제·이름 변경이 확인되면 이전 객체 탭은 사용할 수 없음을 표시하고, 새 이름은 탐색기에서 새로 엽니다. 오래 걸리는 이전 조회는 새 미리보기에 덮어쓰지 않습니다.
