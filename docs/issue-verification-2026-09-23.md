#26의 최초 제안과 달리, 사용자 지시에 따라 **현재 MCP 쓰기 지원을 유지**했다. 새 의존성은
추가하지 않았으며 실제 트랜잭션 상태 API를 사용하기 위해 pg/@types/pg의 최소 버전을
이미 lockfile에 고정되어 있던 8.23.0/8.23.1로 맞췄다.

검증은 운영 DB를 사용하지 않았다. PostgreSQL은 별도의 임시 로컬 클러스터를 사용했다.
실제 Cloud SQL 인증·네트워크 경로, MySQL 실서버, 로그인된 Codex 계정의 실제 모델 응답과
브라우저 로그인 전 과정은 이번 검증에 포함되지 않는다. Mac의 기본 Command Line Tools는
SwiftUIMacros를 찾지 못해, 설치된 Xcode의 도구체인을 `DEVELOPER_DIR`로 지정했다.

권한 비교 범위, 직접 연결의 트랜잭션 실행 제약, 드라이버별 notice 지원 범위는
[실행 결과 문서](query-results.md)에 명시했다. 실행 성공은 변경 의도나 전체 권한 상태의
검증 성공을 뜻하지 않는다. GitHub 이슈 상태와 배포된 설치본은 이 로컬 점검으로 바뀌지 않는다.
