# 로컬 SQL 정렬

정렬 버튼 또는 기존 키보드 단축키로 현재 연결의 PostgreSQL·MySQL·SQLite 규칙을 사용합니다. 정렬은 번들 Node 프로세스 안에서 수행하며 데이터베이스나 AI 서비스에 SQL을 전송하지 않습니다.

`sql-formatter` 15.8.2 (MIT)를 고정 버전으로 사용합니다. 라이선스는 앱의 서드파티 고지 생성 과정에 포함됩니다. 공식 프로젝트: https://github.com/sql-formatter-org/sql-formatter

문자열, 식별자, 주석, 파라미터, 연산자 토큰은 원문과 같아야 적용됩니다. 키워드 대소문자도 보존하고 공백·줄바꿈을 정리합니다. 인용/주석이 미완성이거나 지원하지 않는 문법, 서버 escape 설정에 따라 모호한 역슬래시 인용, 실행형 주석은 원본을 유지하고 메시지를 표시합니다. 프로시저와 DELIMITER 변경은 지원 범위가 아닙니다. 입력 크기는 100,000 UTF-16 코드 단위로 제한합니다.

정렬 전후의 토큰 위치로 선택 영역과 커서를 매핑하고 스크롤 위치를 복원합니다. 하나의 편집 작업으로 적용하여 한 번의 실행 취소로 되돌립니다. 응답을 기다리는 중 사용자가 SQL을 수정하거나 탭·DB를 바꾸면 오래된 정렬 결과는 적용하지 않습니다. 생성된 SQL은 사용자가 명시적으로 정렬할 때만 변경합니다.
