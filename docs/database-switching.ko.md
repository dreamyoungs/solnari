# PostgreSQL 데이터베이스 전환

연결된 PostgreSQL 워크스페이스 상단의 데이터베이스 이름을 눌러 같은 서버의 다른 DB를 엽니다. 목록은 현재 DB 계정의 `CONNECT` 권한이 있고 연결이 허용된 일반 DB를 표시합니다. 목록을 새로고침하거나 **다른 데이터베이스…**에서 이름을 직접 입력할 수 있습니다. 실제 접속은 서버의 인증·권한·연결 제한에 따라 거절될 수 있습니다.

대상 DB에는 현재 프로필의 로그인, 네트워크 경로, TLS와 읽기 전용 설정을 적용한 새 세션을 엽니다. 접속과 스키마 조회가 성공하면 활성 DB를 바꾸고 이전 세션을 닫습니다. 실패하면 기존 DB와 작업 화면을 유지합니다. SSH·Kubernetes 경로는 전환 중 별도 경로를 먼저 열고, 성공한 뒤 이전 경로를 정리합니다.

DB별 쿼리 탭과 결과는 메모리에 보관하여 다시 선택하면 복원합니다. 세션 설정과 임시 테이블은 새 세션으로 이어지지 않습니다. 쿼리·실행 계획·Codex 작업이 진행 중이거나 보고된 트랜잭션이 열려 있으면 전환할 수 없습니다.

저장된 기본 DB는 전환으로 변경되지 않습니다. 재연결과 화면 잠금 후 재접속은 현재 열린 DB를 사용하고, 앱을 다시 시작하면 저장된 기본 DB를 엽니다. 프로필을 편집해 저장하면 해당 설정으로 연결하고 이전 DB 작업 캐시를 초기화합니다.

전환하면 Codex 대화를 초기화하고 MCP의 `connectionID`를 갱신합니다. 쓰기 클라이언트는 `solnari_get_active_connection`으로 새 ID를 조회해야 합니다. 이전 DB에서 받은 ID로 실행하는 쓰기 요청은 거부됩니다.

두 DB 사이의 전환·작업 복원·실패 시 기존 세션 유지·MCP 대상 검증·읽기 전용 권한 유지 테스트는 기존 PostgreSQL 테스트 환경 변수에 `SOLNARI_TEST_POSTGRES_SECOND_DATABASE`를 추가하여 실행합니다. 테스트는 지정된 DB에 객체를 생성하거나 데이터를 변경하지 않습니다.
